# Loomind 工作区外壳设计

## 设计目标

- 一个账号可拥有许多**相互独立**的导图；列表、搜索和最近访问都属于工作区，而不是账号弹窗。
- 新建导图默认从 AI 对话开始；已有内容的用户可以直接导入大纲。两条路径都先确认结构，再创建导图。
- 沿用现有编辑器的画布与编辑工具，只在外面增加导航、导图定位和同步状态。此目录是可点击的 HTML 原型，`editor.html` 的画布仅示意外壳与内容交接，不替代正式编辑器。
- 延续首页的 Linear 风格：深浅中性色、大留白、细边框、清晰文字层级；主要按钮使用明暗反转的中性色，不以紫色突出文字或操作。

## 核心路径

```text
介绍页 → 登录 → 工作区概览
                 ├─ AI 共创（默认）→ 确认结构与模板 → 编辑器
                 ├─ 大纲导入 → 识别层级与选择模板 → 编辑器
                 └─ 全部导图 → 搜索 / 排序 → 编辑器
```

登录后的第一屏先回答两个问题：**如何开始一张新导图**、**如何继续已有导图**。AI 输入占据主位；大纲导入是清晰的第二入口；最近导图紧随其后。拥有很多导图时，用户进入独立的「全部导图」页面检索，而不必在账号菜单里寻找。

## 页面布局

| 页面 | 主区域 | 固定外壳 |
| --- | --- | --- |
| 介绍页 | 产品价值、AI／大纲／多图能力与工作台预览 | 品牌、主题切换、登录入口 |
| 登录 | Turnstile 与 Google 登录顺序 | 品牌、返回介绍页；原型仅演示跳转 |
| 工作区概览 | AI 输入框、示例问题、大纲快捷入口、最近导图 | 左侧导航与底部账号入口、顶部搜索 |
| AI 共创 | 对话记录、输入框、结构草案、生成入口 | 同一导航；对话是默认创建方式 |
| 大纲导入 | 文本输入、层级预览、结构模板选择、生成入口 | 与 AI 共创共用创建页面的导航与进度 |
| 全部导图 | 搜索、排序、导图网格和空结果状态 | 同一导航；适合大量独立导图 |
| 编辑器 | 正式应用中的现有画布及编辑操作 | 工作区导航、导图面包屑、同步状态；原型以可切换的导图／大纲预览示意 |

桌面左侧导航宽约 232px，顶部栏高约 56px。概览和导图库的内容最大宽度约 1180px；编辑器占用剩余空间。侧栏只放概览、全部导图、AI 共创、大纲导入和最近三张导图；账号入口位于底部。窄屏导航以抽屉出现，画布保留主要空间。外壳延续深浅两套中性色；主要按钮在深色模式用浅灰底深色字，在亮色模式用近黑底白字。

## 创建行为

1. **AI 共创：** 用户先描述目标；对话区逐步确认受众、重点与层级，右侧同步显示结构草案；确认后创建一张新的独立导图，再进入编辑器。
2. **大纲导入：** 接受 Markdown 标题、列表或缩进文本；先预览解析出的完整层级，再选择自由导图、逻辑树、时间轴等结构。生成时保留用户文本，不用模板示例内容覆盖大纲。
3. **手动编辑：** 进入编辑器后继续使用当前画布、导图/大纲切换、模板、AI 共创和导出等功能。返回工作区时保留当前导图的保存状态。

## 数据与真实接入

当前应用已经按账号保存多张独立导图；`MindmapSummary` 提供 `id`、`title`、`updatedAt`。现有账号弹窗提供列表与空白新建，编辑器内有 AI 和模板弹窗。接入新外壳时：

1. 将导图列表和新建入口移到工作区；账号弹窗只保留身份、同步与退出。
2. 使用导图 ID 定位编辑器，切换导图时保留当前保存／同步状态；工作区和编辑器共用同一导图列表。
3. AI 草案或解析大纲由用户确认后，分配**新的**导图 ID，再把完整内容写入该导图。重复创建不会覆盖已有导图。
4. 模板只影响新文档的布局和主题，不能用模板示例内容替换用户输入。创建失败、同步失败与空列表都要有明确状态。

当前 AI 生成在未传入模型时使用本地演示流。这个 HTML 原型用本地示例回复、会话存储和布局预览串起体验；真实 AI 对话、云端保存、同步与 Google 登录仍由正式应用负责。原型中导入的大纲会保留完整层级；画布展示最多四个一级分支，完整结构可在大纲视图查看。

## 检查点

- 登录后能从概览进入 AI 创建、大纲导入、全部导图和单张导图。
- 多张导图可搜索；无结果时给出明确空状态。
- AI 和大纲两条路径都先显示结构，再进入编辑器；大纲的嵌套节点保持原有层级，模板选择在预览中可见。
- 原型编辑页只展示外壳与内容交接；正式接入时保留现有编辑器工具。桌面和手机宽度均无页面水平溢出。
- 深浅主题在页面之间保持一致；原型状态明确标识为演示。
