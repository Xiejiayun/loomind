# Loomind 界面与产品路径

## 方向

- 以 Linear 风格的中性色、细边框、清楚的文字层级和克制的动效统一介绍页、登录页、工作区与编辑器。深色和亮色模式均可切换；主按钮使用明暗反转的中性色。
- 一个账号可管理多张独立导图。工作区用于容纳多张导图并邀请成员；单张导图也可单独邀请成员，权限分为可编辑与可查看。
- 沿用现有编辑器的画布、工具栏和编辑方式。编辑器外侧只增加返回工作区、导图名称、同步状态与分享入口。
- 左侧只保留一处 RECENT 导图导航、工作区切换、新建入口和账号信息。首页主区域不重复展示最近导图卡片。

## 现有路径

```text
介绍页 → Google + Turnstile 登录 → 工作区
                              ├─ 从主题创建空白导图 → 编辑器
                              ├─ 粘贴大纲 → 检查完整层级 → 选择模板 → 编辑器
                              ├─ 全部导图 → 搜索 / 排序 / 移动 / 删除 / 分享
                              └─ 创建共享工作区 → 生成邀请链接
邀请链接 → 查看资源和权限 → 登录 → 接受邀请 → 工作区或导图
```

首页以一个输入框承接想法；目前主题会成为新导图的中心节点，用户随后在编辑器中完善。对话式 AI 共建留在默认创建路径的视觉位置，但明确标为即将开放。未来模型选用 Aerial Web，本轮不接入模型、接口或密钥，也不把演示生成呈现为真实 AI。

大纲导入支持 Markdown 标题、列表和缩进文本。预览显示完整层级；模板只影响布局和配色，不替换输入内容。创建时分配新的导图 ID，保存本机草稿，再同步到现有 Cloudflare D1。

分享链接 7 天有效，可由资源所有者撤销。邀请令牌仅在创建时显示明文，数据库只存摘要。接受邀请后，服务端根据已签名会话检查权限；查看者的写入会被拒绝。

## 原型与正式应用

此目录下的 HTML 页面是早期可点击原型。正式 React 页面位于 `apps/web/src`，以上述产品路径为准。`editor.html` 仅示意外壳与编辑器衔接，正式应用继续使用 `@mindmap/editor`。

## 验收重点

- 深浅模式、桌面与手机宽度下都能完成介绍、登录、创建和打开导图；手机侧栏可收起。
- 单个账号可创建并切换多张导图；大纲层级和模板布局在保存、重开后保持一致。
- 工作区和单图邀请的角色、撤销与过期由服务端执行；跨账号访问不能越权。
- 云端同步失败、版本冲突、认证失败都有明确提示，本机草稿不会被静默覆盖。
- AI 入口在正式接入前只显示即将开放状态，不产生假生成内容。
